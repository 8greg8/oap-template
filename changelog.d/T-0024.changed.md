- Breaking: `scripts/release.py` now releases `develop` into `main` instead of only tagging `main`. Without `--yes` it prints the version, the commits and the changelog section and changes nothing. With `--yes` it merges `develop` into `main`, folds the changelog fragments into `CHANGELOG.md`, commits `chore(release): vX.Y.Z`, tags that commit and brings `develop` up to `main`. After a hotfix it runs on `main` and merges `main` into `develop`. `--push` pushes `main`, `develop` and the tag atomically, and `--version vX.Y.Z` overrides the computed version. It refuses a dirty tree, a branch that differs from `origin`, a branch checked out in another worktree, and nothing to release.
- While the latest tag is `v0.x`, a breaking change now bumps minor instead of major, so the first release is `v0.1.0`. From `v1.0.0` on a breaking change still bumps major.
- `scripts/gitflow.sh hotfix finish` now tells you to push `main` and `develop`, then run `scripts/release.py --yes` on `main`.
