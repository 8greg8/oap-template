- `scripts/changelog.py` now rejects a fragment that holds anything but bullet lines, indented
  continuation lines and blank lines, so unchecked text can no longer reach `CHANGELOG.md`.
  Fragments are decoded strictly as UTF-8 on every path, a non-UTF-8 fragment is reported as a
  fragment problem, and one leading BOM is ignored. `--date` accepts only `YYYY-MM-DD`. An
  internal error (a load failure or an unexpected exception) exits 3 with one line, where it
  used to exit 1. Renaming an existing fragment, or deleting and adding it again, no longer
  counts as adding a fragment.
- `.husky/pre-push` checks against the remote the push goes to (`$1`) instead of always
  `origin`, and reports "changelog check failed (exit N)" for any exit status other than a real
  finding, instead of claiming a fragment is missing.
- `scripts/gitflow.sh finish` fetches the base branch before choosing `origin/<base>`, warns and
  uses the local base when the fetch fails, and prints the add-a-fragment advice only when the
  check found a problem.
- `scripts/config/gate.sh` states that it must stay POSIX-sourceable, and a test sources it
  with `sh`.
