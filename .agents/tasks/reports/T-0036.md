## Open questions

1. **Who writes the verify line?** The task's Scope says the verifier "writes the new verify line". `.agents/README.md` has the verifier report and fix nothing, and the orchestrator record the line and commit it. I kept that: the verifier's result ends with the line it found, and the orchestrator records it. Say if the verifier should write it into the report itself.
2. **Fix rounds and records.** The plan says a fix-round verifier "runs the full gate (or cites a record)", while V2 says a verifier never relies on a record. I wrote the narrow form: it cites only a record that an earlier independent verifier's run wrote for the same code. Say if a wider reading was meant.
3. **Pushes to `main` that touch only `RECORD_PATHS`.** The plan says a push to `main` always runs everything. The merged hook skips every gate for such a push (T-0034 raised this). The documents state the skip rule and say that the gate for a `main` push uses `--if-needed --all`, as the code does. They never say that a `main` push always runs the gate.
4. **Plan heading.** The task cites "§ Approvals"; the plan's heading is "Approvals this plan needs". I cited that section.
5. **Edits beyond the listed bullets.** I changed the `CONTRIBUTING.md` fixup-squash rule (squash before the first push; a pushed branch is never rewritten, a fix round adds commits) and removed "before the gate" from the `finish` bullet, since `finish` now gates after the merge. Both fix references to the old flow. I also fixed the stale "fail-fast" wording in `DEV_TOOLING_SPEC.md`, noted by T-0033 and T-0034.

## Lessons learned

- The report file is a `RECORD_PATHS` path but still makes `git status --porcelain` dirty, so a gate run that must write a record has to finish before `report.py new` creates the file in the worktree.
- `.agents/tasks/scripts/housekeep.py` cites `CONTRIBUTING.md` § "Agent verify/resolve workflow" by name, so that heading must not be renamed.
- The task's fragment rules forbid "now" as a word; check the fragment for it before the first commit.
