# T-0037 — Fix the generated README's per-commit gate advice

Write every section below in concise prose (see `CLAUDE.md`'s "Concise
prose in task and report files" section) — required literal content
(Non-goals, acceptance criteria) still stays complete.

## Goal

The README that `init_project.py` writes into a new project gives the current gate advice: check while
working with `scripts/gate.sh --fast`, and know that the pre-push hook and the one independent
verify run the full gate. It no longer tells a reader to run the full gate before every commit.

## Context / current verified state

- `init_project.py:96-110` holds `README_TEXT`. Its `## Checks` section says "Run the gate before
  every commit:" followed by `scripts/gate.sh`. That is the per-commit loop the rules no longer
  have (`CONTRIBUTING.md` § "Agent verify/resolve workflow": iterate with `scripts/gate.sh --fast`,
  one independent verify of the finished branch, no verifier per commit).
- The `pre-commit` hook runs the gate on staged files only, with no tests (`CONTRIBUTING.md` hooks
  section). The `pre-push` hook runs `gate.sh --fast` for a branch other than `develop` and `main`.
- Found by the independent verifier of T-0036, which left it for a follow-up because
  `init_project.py` is outside T-0036's `touches`.
- Re-check these lines against `develop` first and report any discrepancy before editing.

## Scope

- Rewrite the `## Checks` text in `README_TEXT` so it matches `CONTRIBUTING.md` § "Agent verify/resolve
  workflow" and § Git hooks: `scripts/gate.sh --fast` while working, the hooks, and the full
  `scripts/gate.sh` as what the verifier and the `develop`/`main` push checks run. Keep it short, a
